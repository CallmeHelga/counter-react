# 📊 Counter with History — Practice Project

## 📌 Description

This project was created as a practice exercise to improve my React skills.
It is a simple counter application with a clean design and basic functionality.

## Live Demo

[Try it on GitHub Pages](https://callmehelga.github.io/counter-react/)

## 🔹Features:

	•	Simple counter with three actions: add, subtract, and reset.
	•	Total section showing how many times each action was used.
	•	History log of all user interactions with color-coded entries:
	•	Green: added
	•	Red: subtracted
	•	Default: reset
	•	Toggle button to expand or collapse full history.
	•	Toggle button appears only if the history has at least one entry.
	•	Scroll behavior in history block when there are many records.
	•	Accessibility support: all interactive elements have descriptive aria-labels for screen readers.



## 🛠️ Technologies Used
	•	React (useState, conditional rendering)
	•	CSS (flex layout, shadows, scroll control)
